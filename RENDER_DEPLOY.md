# Render deployment

The repository includes a Render Blueprint at `/render.yaml`. Create a new Blueprint in Render from this repository and enter the prompted secret values.

After the first deploy, set these two public URLs:

- `NEXT_PUBLIC_API_URL` on `ailab-frontend`: `https://ailab-backend.onrender.com`
- `CORS_ALLOWED_ORIGINS` on `ailab-backend`: `https://ailab-frontend.onrender.com`

If Render assigns different subdomains, use the actual service URLs shown in the Render dashboard. Redeploy the frontend after changing `NEXT_PUBLIC_API_URL`, because Next.js embeds `NEXT_PUBLIC_*` values during the image build.

The Blueprint creates Render Postgres and passes its host, port, database, username, and password to Spring Boot. `JWT_SECRET` is generated by Render. Seeding is disabled by default in production. If the project requires a bootstrap admin, enable `SEED_ENABLED` temporarily and provide the seed credentials, then set it back to `false` and redeploy.
