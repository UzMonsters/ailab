# Extended Element Property Data Sources & Evidence Methodology

## Data Provenance Standards

All 118 element property profiles in the Periodic Table module are backed by primary scientific reference standards:

1. **CRC Handbook of Chemistry and Physics (104th Edition, 2023–2024)**
   - **Source Identifier**: `CRC-HANDBOOK-104`
   - **Title**: *CRC Handbook of Chemistry and Physics, 104th Edition*
   - **Publisher**: CRC Press / Taylor & Francis Group
   - **Version**: 104th Edition (2023–2024)
   - **Access Date**: 2026-08-04
   - **Fields Covered**: Valencies, standard oxidation states, Pauling electronegativities, empirical/covalent/van der Waals/ionic radii, densities, phase transition temperatures (melting, boiling, sublimation), and visual appearances.
   - **Evidence Classification**: `EVALUATED` for elements Z=1 to Z=117; `PREDICTED` for superheavy elements (e.g. Z=118 Oganesson).
   - **Licensing & Reuse Note**: Scientific attribution is provided for data provenance and reference transparency. Source attribution does not itself establish public domain status or unrestricted commercial redistribution rights. Full dataset reproduction remain limited by publisher terms; usage within this engine is restricted to internal educational, computational, and reference evaluation purposes.

2. **IUPAC Commission on Isotopic Abundances and Atomic Weights (CIAAW 2024)**
   - **Source Identifier**: `CIAAW-2024`
   - **Title**: *Standard Atomic Weights of the Elements 2024*
   - **Publisher**: International Union of Pure and Applied Chemistry (IUPAC)
   - **Fields Covered**: Dataset versioning (`extended-properties-v1.0.0`) and standard atomic weight range integration.
   - **Licensing & Reuse Note**: Freely usable scientific reference standard.

3. **NIST Physical Reference Data**
   - **Source Identifier**: `NIST-PHYS-2024`
   - **Title**: *NIST Atomic Spectra Database & Physical Reference Data*
   - **Publisher**: National Institute of Standards and Technology
   - **Fields Covered**: Reference state temperature (273.15 K / 298.15 K) and pressure (100 kPa / 1 atm) conditions.
   - **Licensing & Reuse Note**: Public domain US Government scientific dataset.
