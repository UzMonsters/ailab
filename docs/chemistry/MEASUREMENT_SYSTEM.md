# Chemistry Measurement System Documentation

This document describes the foundational scientific measurement system implemented in the `chemistry-engine` module. The system provides safe, immutable, type-safe, and dimension-aware value objects for all calculations.

---

## 1. Precision and Scaling Policy

All physical quantities represent their value internally using `BigDecimal` and normalize it to a canonical SI unit.

- **Authoritative Calculations**: Operations use `MathContext.DECIMAL128` (`CALCULATION_CONTEXT`) to minimize intermediate rounding drift.
- **Construction Rules**: Values must always be initialized from string literals or exact integers. Floating point constructors (such as `new BigDecimal(double)`) are forbidden.
- **Exact Equality**: Checked using `BigDecimal.compareTo(...) == 0`, which is scale-independent (`1.0` is equal to `1.00`).
- **HashCode**: Scaled-independent hash codes are generated by normalizing trailing zeros: `value.stripTrailingZeros().hashCode()`.
- **Approximate Equality**: Checked using `ScientificMath.isApproximatelyEqual(first, second, absoluteTolerance, relativeTolerance)`.
  - Formula: `|first - second| <= absoluteTolerance` OR `|first - second| / max(|first|, |second|) <= relativeTolerance`
  - Tolerances must be non-negative.

## 2. Supported Quantity Matrix

| Quantity Type | Canonical Unit | Supported Units (Symbols) | Conversions to Canonical Unit |
| :--- | :--- | :--- | :--- |
| **Mass** | Gram (`g`) | Milligram (`mg`), Gram (`g`), Kilogram (`kg`) | `1 mg = 0.001 g`, `1 kg = 1000 g` |
| **Volume** | Liter (`L`) | Microliter (`µL`/`μL`/`uL`), Milliliter (`mL`), Liter (`L`) | `1 µL = 1e-6 L`, `1 mL = 1e-3 L` |
| **Amount of Substance** | Mole (`mol`) | Millimole (`mmol`), Mole (`mol`) | `1 mmol = 0.001 mol` |
| **Temperature** | Kelvin (`K`) | Celsius (`°C`/`C`/`degC`), Kelvin (`K`) | `T(K) = T(°C) + 273.15` (Offset) |
| **TemperatureDelta** | Kelvin (`K` delta) | Celsius delta, Kelvin delta (magnitudes) | `1 °C delta = 1 K delta` (Offsets do NOT apply) |
| **Absolute Pressure** | Pascal (`Pa`) | Pascal (`Pa`), Kilopascal (`kPa`), Atmosphere (`atm`), Bar (`bar`) | `1 kPa = 1000 Pa`, `1 atm = 101325 Pa`, `1 bar = 100000 Pa` |
| **Molar Concentration** | Mole/Liter (`mol/L`) | Mole/Liter (`mol/L`), Millimole/Liter (`mmol/L`) | `1 mmol/L = 0.001 mol/L` |
| **Mass Concentration** | Gram/Liter (`g/L`) | Gram/Liter (`g/L`), Milligram/Liter (`mg/L`) | `1 mg/L = 0.001 g/L` |
| **Percentage Concentration** | N/A | Requires basis: `MASS_PER_MASS` (`w/w`), `MASS_PER_VOLUME` (`w/v`), `VOLUME_PER_VOLUME` (`v/v`) | No cross-basis comparisons or additions allowed. |
| **Energy** | Joule (`J`) | Joule (`J`), Kilojoule (`kJ`) | `1 kJ = 1000 J` |
| **Duration** | Second (`s`) | Millisecond (`ms`), Second (`s`), Minute (`min`), Hour (`h`) | `1 ms = 0.001 s`, `1 min = 60 s`, `1 h = 3600 s` |

## 3. Quantity Verification Rules

1. **Non-negative Quantities**:
   - Mass, Volume, AmountOfSubstance, Temperature, Pressure, Concentration, and Duration cannot have negative values.
   - Any mathematical operations (addition, subtraction, scalar multiplication, division) resulting in a negative value will throw a `NegativeQuantityException`.
   - Multiplication/division by negative scalars is strictly rejected for these quantities.
2. **Signed Quantities**:
   - Energy and TemperatureDelta support signed values (can be negative).
   - Multiplication/division by negative scalars is permitted.
3. **Cross-Dimensional Operations**:
   - Dimension-specific classes strictly block cross-dimensional conversions (e.g. converting mass to volume is blocked at compile time).
4. **Temperature offset vs. Magnitude**:
   - Absolute `Temperature` conversions apply the `273.15` Kelvin offset.
   - `TemperatureDelta` represents magnitude differences, and does **not** apply the offset.
   - Adding two absolute temperatures is blocked. Applying a `TemperatureDelta` to a `Temperature` is allowed.
   - Subtracting two absolute temperatures produces a `TemperatureDelta`.
5. **Percentage Concentration Basis**:
   - Must have an explicit `ConcentrationBasis`.
   - Comparing or adding percentage concentrations with different bases will throw `IncompatibleUnitException`.
