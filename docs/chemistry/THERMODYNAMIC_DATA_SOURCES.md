# Thermodynamic Data Sources

Dataset: `thermodynamic-reference-v1.0.0`

Primary source identifier: `NIST-WEBBOOK`

Citation: NIST Chemistry WebBook thermochemistry tables and CODATA reference-state conventions.

Reuse limitation: the checked-in data is a minimal cited educational subset. Verify upstream licensing before redistributing the values as a standalone thermodynamic data table.

## Coverage

Seeded profiles: H2, O2, H2O liquid and gas, CO2, CO, CH4, HCl, NH3, H2O2, ethanol, acetic acid, NaOH, NaCl, CaCO3, NaHCO3 and Na2CO3.

The dataset prioritizes compounds already present in the reaction, acid/base, solubility and carbonate-family work. Unsupported compounds remain absent until a defensible source value and matching compound catalogue record are available.

## Conditions

All seeded records are for 298.15 K and 1 bar. Physical state and standard-state convention are explicit on every record. Values are not interpolated or converted across phases.
