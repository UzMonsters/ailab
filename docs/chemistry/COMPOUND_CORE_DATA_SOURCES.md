# Compound Core Data Sources & Scientific Provenance

## Data Provenance
- **Chemical Formulas, Names, CAS Numbers, PubChem CIDs**: CRC Handbook of Chemistry and Physics, 104th Edition (CRC Press / Taylor & Francis Group). Provenance code `CRC-HANDBOOK-104`.
- **Standard Atomic Weights & Interval Bounds**: CIAAW 2021 / IUPAC 2024 via versioned `v1.1.0` Periodic Table Catalogue (`chemistry.periodic_table_catalog_versions`).
- **Molar Mass Calculations**: Computed dynamically by `MolarMassCalculatorImpl` (`v1.0.0-interval-propagation`).

## Dataset Versioning
- Compound Catalogue Version: `compound-core-v1.0.0`
- Element Catalogue Version: `v1.1.0`
